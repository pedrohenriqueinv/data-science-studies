What HTTP status code signifies that the client has exceeded API rate limits?	"<b>English:</b> HTTP 429 Too Many Requests. The client should check the 'Retry-After' response header before sending another request.<br><br><b>Portuguese:</b> HTTP 429 Too Many Requests. O cliente deve inspecionar o header 'Retry-After' antes de tentar novamente."
Why is requests.Session() more efficient than standalone requests.get() calls?	"<b>English:</b> A session maintains persistent TCP connections via connection pooling (HTTP Keep-Alive), eliminating repetitive TLS/TCP connection handshakes across multiple requests.<br><br><b>Portuguese:</b> Mantém conexões TCP persistentes via pool de conexões (HTTP Keep-Alive), eliminando o overhead de negociar handshakes TLS/TCP a cada requisição."
What is Exponential Backoff and why is it used in data engineering API clients?	"<b>English:</b> An error-handling strategy where the wait time between retries doubles progressively (1s, 2s, 4s, 8s), preventing the client from overwhelming a recovering server.<br><br><b>Portuguese:</b> Estratégia de repetição onde o tempo de espera dobra a cada falha (1s, 2s, 4s, 8s), evitando sobrecarregar servidores instáveis."
What does the response.raise_for_status() method do in Python requests?	"<b>English:</b> It raises an HTTPError exception if the HTTP response code indicates an error (4xx client error or 5xx server error), halting pipeline corruption.<br><br><b>Portuguese:</b> Dispara uma exceção HTTPError caso o código HTTP seja de erro (4xx ou 5xx), evitando que dados corrompidos sigam no pipeline."
What is the difference between Offset-based and Cursor-based API pagination?	"<b>English:</b> Offset pagination specifies page numbers and can suffer from duplicated/skipped records when data changes during retrieval. Cursor pagination passes an opaque pointer to the last retrieved record, ensuring stable pagination.<br><br><b>Portuguese:</b> Paginação por Offset usa deslocamentos de página e pode perder dados se novos registros forem inseridos. Paginação por Cursor usa um ponteiro imutável do último item visto, garantindo estabilidade."
