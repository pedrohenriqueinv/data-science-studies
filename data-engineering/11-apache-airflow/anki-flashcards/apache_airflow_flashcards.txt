What are the 5 core components of the Apache Airflow architecture?	"<b>English:</b> 1. Webserver (UI), 2. Scheduler, 3. Metadata Database, 4. Executor, 5. Workers.<br><br><b>Portuguese:</b> 1. Webserver (UI), 2. Scheduler, 3. Banco de Metadados, 4. Executor, 5. Workers."
What is the TaskFlow API in Airflow 2.x/3.x and why is it preferred?	"<b>English:</b> A paradigm that uses Python decorators like @task and @dag to declare tasks and dependencies natively, automatically managing XCom data passing between functions.<br><br><b>Portuguese:</b> Paradigma que utiliza decoradores como @task e @dag para declarar tarefas nativamente, gerenciando automaticamente a troca de dados via XCom entre funções."
Why is mode='reschedule' mandatory for long-waiting Airflow Sensors in production?	"<b>English:</b> 'poke' holds worker slots blocked while waiting, starving the cluster. 'reschedule' frees the worker slot between checks and re-enters the queue when the poke interval arrives.<br><br><b>Portuguese:</b> O modo 'poke' bloqueia o slot do worker durante toda a espera, esgotando recursos. O modo 'reschedule' libera o worker entre checagens, alocando-o apenas no instante do teste."
What is an Airflow DAG and what does the 'Acyclic' property guarantee?	"<b>English:</b> A Directed Acyclic Graph representing task dependencies. The acyclic guarantee ensures workflows contain no circular dependencies or infinite loops.<br><br><b>Portuguese:</b> Grafo Direcionado Acíclico de tarefas. A propriedade acíclica garante que o fluxo não possui dependências circulares ou loops infinitos."
Why should large datasets (>10MB) NEVER be passed directly through XComs?	"<b>English:</b> XCom values are serialized into the Airflow metadata database backend. Passing large DataFrames causes database bloat, latency spikes, and Out-Of-Memory crashes. Pass object storage URIs (s3://...) instead.<br><br><b>Portuguese:</b> Valores de XCom são serializados no banco de metadados relacional do Airflow. Grandes volumes causam sobrecarga de I/O e estouro de memória no banco; trafegue apenas URIs de armazenamento (s3://...)."
