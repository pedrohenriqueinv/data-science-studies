What is the difference between IaaS, PaaS, and FaaS in Cloud Data Engineering?	"<b>English:</b> IaaS provides raw virtual machines (AWS EC2). PaaS provides managed platforms and database instances (AWS RDS). FaaS/Serverless runs event-driven code snippets on demand without server management (AWS Lambda, Google Cloud Functions).<br><br><b>Portuguese:</b> IaaS fornece VMs brutas (AWS EC2). PaaS oferece plataformas e bancos gerenciados (AWS RDS). FaaS/Serverless executa funções sob demanda sem gestão de servidores (AWS Lambda, Cloud Functions)."

Why are tuples more memory-efficient than lists in CPython?	"<b>English:</b> Tuples are immutable, so Python allocates an exact, fixed-size memory block without the dynamic over-allocation buffer that lists require to support amortized append().<br><br><b>Portuguese:</b> Tuplas são imutáveis, permitindo alocação em bloco exato de memória sem o overhead de superdimensionamento de buffers que listas usam para suportar append()."
What is a collections.deque and when should a data engineer use it over a list?	"<b>English:</b> A double-ended queue implemented as a doubly-linked list of memory blocks. It provides O(1) appends and pops from both ends, making it ideal for streaming sliding windows and FIFO buffers.<br><br><b>Portuguese:</b> Fila de duas pontas implementada como lista duplamente encadeada. Oferece O(1) para inserção e remoção em ambas as pontas, ideal para janelas deslizantes em streaming e buffers FIFO."
