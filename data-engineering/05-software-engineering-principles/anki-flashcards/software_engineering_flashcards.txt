What is the main role of __init__.py in a Python directory?	"<b>English:</b> It marks the directory as a Python package, defines package-level exposed symbols, and executes package initialization logic.<br><br><b>Portuguese:</b> Demarca o diretório como um pacote Python importável, define os símbolos públicos expostos e executa a inicialização do módulo."
What does PEP 8 mandate regarding function and variable naming conventions?	"<b>English:</b> Function and variable names should be lowercase, with words separated by underscores (snake_case) to improve readability.<br><br><b>Portuguese:</b> Devem ser grafados em minúsculas, com palavras separadas por sublinhado (snake_case) para máxima legibilidade."
What is the difference between a class attribute and an instance attribute in Python?	"<b>English:</b> A class attribute is shared across all instances of the class. An instance attribute belongs exclusively to a specific instance and is typically initialized inside <code>__init__</code> via <code>self.attr</code>.<br><br><b>Portuguese:</b> Atributo de classe é compartilhado por todas as instâncias da classe. Atributo de instância pertence exclusivamente àquele objeto específico e é inicializado via <code>self.attr</code> no <code>__init__</code>."
What is the purpose of pytest fixtures defined with @pytest.fixture?	"<b>English:</b> Fixtures provide repeatable, modular test dependencies (such as mock database connections, test DataFrames, or temp files) injected automatically into test functions.<br><br><b>Portuguese:</b> Fixtures fornecem dados de teste ou dependências reutilizáveis (como conexões de teste ou DataFrames fictícios) injetados automaticamente nas funções de teste."
What is pyproject.toml and why does modern Python packaging favor it over setup.py?	"<b>English:</b> <code>pyproject.toml</code> is the standardized declarative configuration file (PEP 518/621) defining build tools, metadata, and dependencies, avoiding arbitrary code execution during package installs.<br><br><b>Portuguese:</b> É o arquivo declarativo padronizado (PEP 518/621) para metadados, ferramentas de build e dependências, evitando execução arbitrária de código durante a instalação."
