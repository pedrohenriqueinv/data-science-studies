# 🎯 Active Learning Methodology (70 / 20 / 10 Framework)

To master Data Engineering in Python, avoid passive reading. Implement the **70/20/10 active learning doctrine**:

1. **70% Hands-On Code (Terminal & IDE):**
   * Execute scripts under `/scripts` and `/dags`.
   * Complete every module's Capstone Challenge from a blank sheet before looking at solutions.
   * Debug intentional exceptions, profile memory usage, and inspect execution plans.

2. **20% Active Recall & Spaced Repetition (Anki):**
   * Import the `.txt` flashcard decks located in `anki-flashcards/` into [Anki](https://apps.ankiweb.net/).
   * Practice 15 minutes of daily spaced repetition to retain CLI flags, decorators, and architectural trade-offs.

3. **10% Conceptual Architecture:**
   * Review comparison matrices (ETL vs ELT, Row vs Columnar, Poke vs Reschedule).
   * Understand memory layouts and hardware mechanics (RAM buffers vs Python object pointers).
