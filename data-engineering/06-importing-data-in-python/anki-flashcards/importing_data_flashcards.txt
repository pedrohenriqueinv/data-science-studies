Why is using 'with open(...) as f:' mandatory when doing file I/O in Python?	"<b>English:</b> It guarantees that the file descriptor is cleanly closed and OS resources are released immediately, even if an exception or crash occurs during execution.<br><br><b>Portuguese:</b> Garante que o descritor de arquivo seja fechado e recursos do SO liberados imediatamente, mesmo se ocorrer uma exceção ou falha durante o processamento."
What is the primary technical use case for the HDF5 (.h5) binary format in data engineering?	"<b>English:</b> Storing massive, hierarchically organized scientific and sensor arrays (>100GB) with support for on-disk chunking, compression, and sub-slice indexing without loading the full file into memory.<br><br><b>Portuguese:</b> Armazenamento de grandes volumes (>100GB) de dados científicos ou de sensores em estrutura hierárquica, permitindo leitura por fatias sem carregar todo o arquivo na memória RAM."
Why is the Python 'pickle' module dangerous when importing data from untrusted sources?	"<b>English:</b> Pickle can deserialize arbitrary byte streams into Python executable code, creating critical Remote Code Execution (RCE) vulnerabilities.<br><br><b>Portuguese:</b> O pickle pode desserializar fluxos de bytes em instruções executáveis de Python, abrindo vulnerabilidade crítica de execução remota de código (RCE)."
How does SQLAlchemy's create_engine differ from an active database connection?	"<b>English:</b> <code>create_engine</code> establishes a connection pool factory and dialect manager; it does not open a physical TCP connection to the database until an operation or <code>.connect()</code> is called.<br><br><b>Portuguese:</b> <code>create_engine</code> cria uma fábrica de conexões gerenciada por pool; ele não abre uma conexão física de rede TCP até que uma operação ou <code>.connect()</code> seja executada."
What parameter in pd.read_csv prevents high memory consumption when reading specific columns?	"<b>English:</b> <code>usecols=['col1', 'col2']</code>, which directs Pandas to parse and allocate memory only for the specified columns.<br><br><b>Portuguese:</b> <code>usecols=['col1', 'col2']</code>, que instrui o Pandas a carregar e alocar na RAM exclusivamente as colunas especificadas."
