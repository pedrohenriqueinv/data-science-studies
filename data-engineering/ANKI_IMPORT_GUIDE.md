# 🗂️ How to Import Flashcard Decks into Anki

Every module in this repository provides a dedicated active recall deck under `anki-flashcards/*.txt`.

### Step-by-Step Import Instructions:
1. Download and open [Anki Desktop](https://apps.ankiweb.net/).
2. Click **File -> Import** (or press `Ctrl+I`).
3. Select any `.txt` flashcard file from this repository (e.g. `data-engineering/11-apache-airflow/anki-flashcards/apache_airflow_flashcards.txt`).
4. In the Anki Import dialog:
   * **Field separator:** Select `Tab`.
   * **Allow HTML in fields:** Ensure this checkbox is **CHECKED** (to render bold tags and line breaks).
   * **Card Type:** Basic (Front / Back).
5. Click **Import**. Practice 15-20 minutes daily for maximum retention!
