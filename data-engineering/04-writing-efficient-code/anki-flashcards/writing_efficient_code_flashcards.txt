What does 'efficient code' mean in the context of Python development and data pipelines?	"<b>English:</b> Code that achieves optimal runtime execution and minimal RAM allocation while maintaining idiomatic readability conforming to PEP 20 (The Zen of Python).<br><br><b>Portuguese:</b> Código que conjuga tempo de execução ótimo e consumo mínimo de memória RAM, mantendo legibilidade idiomática aderente à PEP 20."
What is NumPy Broadcasting and how does it save memory?	"<b>English:</b> Broadcasting allows arithmetic operations between arrays of different shapes without physically copying or replicating data in RAM; the smaller array is virtually expanded across the larger one.<br><br><b>Portuguese:</b> Capacidade de aplicar operações aritméticas entre arrays de dimensões distintas sem duplicar dados fisicamente na memória RAM."
Why is iterating over a Pandas DataFrame with .iterrows() considered an anti-pattern?	"<b>English:</b> <code>.iterrows()</code> converts each row into a distinct Pandas Series object on the fly, creating severe boxing/unboxing overhead and running orders of magnitude slower than <code>.itertuples()</code> or vectorized operations.<br><br><b>Portuguese:</b> <code>.iterrows()</code> converte cada linha em um novo objeto Series do Pandas, gerando enorme overhead de instanciação e rodando ordens de magnitude mais lento que <code>.itertuples()</code> ou vetorização."
How does accessing columns differ between .iterrows() and .itertuples()?	"<b>English:</b> In <code>.iterrows()</code>, values are accessed via dictionary-like bracket notation (<code>row['col']</code>). In <code>.itertuples()</code>, values are accessed via direct attribute access (<code>row.col</code>), which is significantly faster.<br><br><b>Portuguese:</b> No <code>.iterrows()</code> o acesso é feito por colchetes (<code>row['col']</code>). No <code>.itertuples()</code> o acesso é direto por atributo (<code>row.col</code>), muito mais rápido."
What is the difference between line_profiler and memory_profiler?	"<b>English:</b> <code>line_profiler</code> measures CPU execution time line-by-line, whereas <code>memory_profiler</code> tracks physical RAM allocation and deallocation per line.<br><br><b>Portuguese:</b> O <code>line_profiler</code> afere o tempo de CPU linha a linha; o <code>memory_profiler</code> rastreia a alocação e liberação de memória RAM por linha."
