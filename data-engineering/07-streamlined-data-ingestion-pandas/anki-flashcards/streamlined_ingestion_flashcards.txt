What happens when pd.read_csv is called with the chunksize parameter?	"<b>English:</b> Instead of loading the entire dataset into memory at once, it returns a <code>TextFileReader</code> generator object that yields bounded chunks of DataFrame rows one at a time.<br><br><b>Portuguese:</b> Em vez de carregar todo o arquivo na memória, retorna um gerador <code>TextFileReader</code> que produz fatias menores de linhas (DataFrames) sob demanda."
How does converting low-cardinality string columns to category type optimize memory?	"<b>English:</b> It replaces redundant string pointer allocations with a single integer lookup index array, saving up to 80-90% of RAM.<br><br><b>Portuguese:</b> Substitui strings repetidas por uma tabela de códigos inteiros, reduzindo o consumo de memória RAM em até 80-90%."
What is the function of sheet_name=None in pd.read_excel?	"<b>English:</b> It loads all worksheets in the workbook simultaneously, returning a dictionary where keys are sheet names and values are the corresponding DataFrames.<br><br><b>Portuguese:</b> Carrega todas as abas da planilha simultaneamente, retornando um dicionário onde as chaves são os nomes das abas e os valores são os DataFrames."
What Pandas function is used to flatten deeply nested JSON structures into a 2D table?	"<b>English:</b> <code>pd.json_normalize()</code>, which flattens nested dictionaries into dot-notated column names.<br><br><b>Portuguese:</b> <code>pd.json_normalize()</code>, que desaninha estruturas hierárquicas em colunas com notação de ponto."
Why should you specify explicit dtypes in pd.read_csv for production pipelines?	"<b>English:</b> It prevents costly dynamic type inference across rows, guarantees deterministic schema constraints, and prevents Out-Of-Memory errors by allocating the minimum required byte widths.<br><br><b>Portuguese:</b> Elimina a inferência dinâmica de tipos linha a linha, garante consistência de esquema e evita estouro de memória (OOM) ao alocar tamanhos exatos de bytes."
