What is a Git branch in terms of low-level architecture?	"<b>English:</b> A 41-byte movable pointer containing the 40-character SHA-1 hash of the latest commit on that line of development.<br><br><b>Portuguese:</b> Um ponteiro móvel leve de 41 bytes que armazena o hash SHA-1 de 40 caracteres do commit mais recente daquela linha de histórico."
What is the difference between git merge (Fast-Forward) and a 3-way merge?	"<b>English:</b> A fast-forward merge simply advances the branch pointer when history has not diverged. A 3-way merge reconciles two divergent lines of history using their common ancestor and generates a new merge commit with two parents.<br><br><b>Portuguese:</b> O merge fast-forward apenas avança o ponteiro quando não há divergência. O merge 3-way une duas linhas divergentes usando o ancestral comum e gera um novo commit de fusão com dois pais."
What triggers a merge conflict in Git?	"<b>English:</b> When two branches make conflicting modifications to the exact same line of a file, or when one branch modifies a file that the other branch deleted.<br><br><b>Portuguese:</b> Quando duas branches alteram a mesma linha de um arquivo de formas diferentes, ou quando uma branch edita um arquivo que a outra deletou."
What is the crucial difference between git fetch and git pull?	"<b>English:</b> <code>git fetch</code> downloads new commits from the remote repository to remote-tracking branches (e.g., origin/main) without touching your working directory. <code>git pull</code> performs fetch followed by an automatic merge into your current branch.<br><br><b>Portuguese:</b> <code>git fetch</code> baixa commits do repositório remoto para branches de rastreamento (ex: origin/main) sem alterar a pasta de trabalho. <code>git pull</code> executa o fetch e em seguida tenta mesclar automaticamente na branch atual."
How do you safely abort an in-progress merge conflict and return to the prior clean state?	"<b>English:</b> Run <code>git merge --abort</code>.<br><br><b>Portuguese:</b> Executa-se o comando <code>git merge --abort</code>."
