## 1. Data Integrity Dimensions & Constraints

Raw extracted data is almost never clean. Data engineers must enforce four core constraints:

1. **Type Constraints:** Numeric IDs accidentally parsed as floats; date strings without ISO formatting.
2. **Range Constraints:** Negative ages, future transaction dates, or impossible sensor percentages (>100%).
3. **Uniqueness Constraints:** Redundant duplicate events generated by network retries.
4. **Referential / Categorical Constraints:** Country codes or status values not belonging to the allowed domain catalog.

## 2. Text Normalization & Regular Expressions

```python
# Strip whitespace, lower-case, and purge special characters:
df["phone"] = df["raw_phone"].str.replace(r"[^0-9]", "", regex=True)
df["email"] = df["raw_email"].str.strip().str.lower()
```
